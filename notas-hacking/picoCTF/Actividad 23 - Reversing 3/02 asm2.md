#### Description
What does asm2(0xc,0x1d) return? Submit the flag as a hexadecimal value (starting with '0x'). NOTE: Your submission for this question will NOT be in the normal flag format. [Source](https://challenge-files.picoctf.net/c_fickle_tempest/03ef6d65b33a69a3aee644df1385c84ab7c9e3b45d81fe05ad144e1460a9eaaf/test.S)

**Solución** 

**`0x131`**

- Se reflejo el estado de las variables locales (`ebp-0x4` y `ebp-0x8`) justo después de ejecutar la primera iteración del bucle.
- Se uso Python para comprobar matemáticamente la primera vuelta (`0x1d + 0x1 = 0x1e` y `0xc + 0xe4 = 0xf0`).
- Se dividió el límite máximo entre el incremento (`0xf5cf / 0xe4`) para descubrir que el ciclo se repetiría **276 veces**.
- Luego sumamos directamente esas 276 iteraciones al valor inicial en decimal de la primera variable (`29 + 276 = 305`).
- Después se convirtió el total a hexadecimal (`hex(305)`), obteniendo directamente la bandera del reto: **`0x131`**.
